# PhaseJourney

**A powerful Minecraft Phase Management System Mod**

*Let players gradually unlock game content through the phase system, creating a more challenging and progressive gaming experience*

---

---

## Main Features

#### ✅ Player Phase System
- Define custom phases for players and manage their progress
- Support dynamic addition and removal of phases
- Provide rich API for other mods to integrate

#### ✅ Block Phase
- Completely replace blocks based on phases (including but not limited to: rendering, functionality, clicking, breaking, attributes)

#### ✅ Item Phase
- Limit whether players can possess specific items based on phases

#### ✅ Recipe Phase
- Limit whether players can craft specific recipes based on phases
- Support restrictions on multiple recipe types

**Supported Recipe Types:**
- **Vanilla Recipes**: Crafting Table, Furnace, Blast Furnace, Smoker, Campfire, Stonecutter, Smithing Table
- **Create Mod**: Crushing, Cutting, Grinding, Mixing & Stirring, Pressing, Sandpaper Polishing, Sequential Assembly
- **Immersive Engineering**: Alloy Smelter, Blast Furnace, Arc Furnace, Bottling Machine, Coke Oven, Crusher, Fermenter, Metal Press, Mixer, Refinery, Sawmill, Squeezer
- **Industrial Foregoing**: Dissolution Chamber, Liquid Extractor, Laser Drill, Fluid Laser Drill, Stonework Factory
- **Mekanism**: Crusher, Enrichment, Smelting, Chemical Injection, Metallurgic Infusion, Fusion, Separator, Washer, Evaporation, Activation, Centrifuging, Crystallizing, Dissolution, Compression, Purification, Injection, Nuclear Synthesis, Energy Conversion, Chemical Conversion, Oxidation, Pigment Extracting, Painting, Reaction, Rotary, Sawing

#### ✅ Crop Phase
- Limit whether specific crops are allowed to grow based on phases

#### ✅ Potion Effect Phase
- Limit whether entities can be granted specific effects based on phases

#### ✅ Dimension Phase
- Limit whether players can enter or leave specified dimensions based on phases

#### ✅ Enchantment Phase
- Limit whether player equipment can have specific enchantments based on phases

#### ✅ Entity Interaction Phase
- Limit various interactions with tamable entities based on phases, including but not limited to: taming, breeding, riding, placing blocks, breaking blocks, using items, attacking
