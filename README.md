# PhaseJourney - 阶段之旅

**一个强大的Minecraft阶段管理系统模组**

*让玩家通过阶段系统逐步解锁游戏内容，创造更有挑战性和渐进性的游戏体验*

---

## 主要功能

#### ✅ 玩家阶段系统
- 为玩家定义自定义阶段并管理他们的进度
- 支持动态添加和移除阶段
- 提供丰富的API供其他模组集成

#### ✅ 方块阶段
- 根据阶段完整替换方块（包括但不限于渲染、功能、点击、破坏、属性）

#### ✅ 物品阶段
- 根据阶段限制玩家是否可以拥有特定物品

#### ✅ 配方阶段
- 根据阶段限制玩家是否可以制作特定配方
- 支持多种配方类型的限制

**已支持的配方类型：**
- **原版配方**：工作台、熔炉、高炉、烟熏炉、营火、切石机、锻造台
- **机械动力**：粉碎、切削、研磨、混合搅拌、塑形、砂纸抛光、序列化组装
- **沉浸工程**：合金炉、高炉、电弧炉、装瓶机、焦炉、破碎机、发酵罐、金属冲压机、搅拌机、炼油厂、锯木机、挤压机
- **工业先锋**：溶解室、液体提取器、镭射钻孔、流体镭射钻孔、造石加工
- **通用机械**：破碎、富集、冶炼、化学注入、冶金灌注、融合、分离、洗涤、蒸发、激活、离心、结晶、解散、压缩、净化、注射、核合成、能量转换、化学转化、氧化、色素提取、颜料混合、绘画、反应、旋转、锯切

#### ✅ 作物阶段
- 根据阶段限制对应作物是否允许生长


#### ✅ 药水效果阶段
- 根据阶段限制实体是否可以被给予特定效果

#### ✅ 维度阶段
- 根据阶段限制是否可以进入或离开指定维度

#### ✅ 附魔阶段
- 根据阶段限制玩家装备是否可以拥有特定附魔

#### ✅ 实体交互阶段
- 根据阶段限制可驯服实体的各种交互 包括但不限于：驯服、繁育、骑乘、放置方块、破坏方块、使用物品、攻击

## 🔗 模组集成

### ✅ 已完成的集成

#### 天命时刻 (Heaven Destiny Moment)
- 根据阶段，限制是否可以创建事件时刻

#### 等价交换 (ProjectE)
- 根据阶段限制是否可以将物品放入转换桌

#### 沉浸工程 (Immersive Engineering)
- 根据阶段限制是否搭建机器

#### 饰品 (Curios)
- 根据阶段限制是否解锁饰品槽

#### 铁魔法 (Iron's Spells 'n Spellbooks)
- 根据阶段限制法术的释放

#### 机械动力 (Create)
- 根据阶段限制是否允许构成无限液体池

#### 车万女仆 (Touhou Little Maid)
- 根据阶段限制女仆的工作模式切换

#### 传送石碑 (Waystones)
- 根据阶段限制是否允许传送
